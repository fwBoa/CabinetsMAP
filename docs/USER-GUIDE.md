# Mode d'emploi — Carte du réseau CEGC

> Guide utilisateur. 2 minutes de lecture.

## La carte

- **Chaque point coloré = un cabinet partenaire.** La couleur identifie le cabinet (elle est choisie par l'administration).
- **Cliquez sur un point** (ou sur un cabinet dans la liste) pour afficher sa fiche : adresse, téléphone, emails, tribunaux et cours d'appel couverts.
- **Recherchez** un cabinet par nom, ou un département par son numéro ou son nom. La carte zoome automatiquement sur le résultat.
- **Liste latérale** : elle reprend tous les cabinets ; cliquez pour centrer la carte.
- **Bouton globe 🌐** : recentre la vue sur l'outre-mer (DOM-TOM-COM).
- **Bouton réinitialiser ↺** : revient à la vue France entière.

## Lire une fiche cabinet

| Champ | Signification |
|---|---|
| Adresse | Adresse postale du cabinet |
| Téléphone / Emails | Contact direct |
| Tribunaux | Tribunaux judiciaires où le cabinet intervient |
| Cours d'appel | Cours d'appel de rattachement |
| Départements | Zones de couverture (cliquables : le point correspondant se met en surbrillance) |

## À savoir

- **Les données sont maintenues à jour par l'administration du réseau.** En cas d'information obsolète (déménagement, nouveau contact), signalez-le au responsable du réseau — ne modifiez rien vous-même.
- **La carte fonctionne sur mobile** : pincez pour zoomer, glissez pour déplacer.
- **Un département sans couleur** signifie qu'aucun cabinet partenaire ne le couvre à ce jour.

## Espace admin (réservé)

L'accès administrateur est réservé aux gestionnaires du réseau :

1. Connectez-vous sur `/admin` avec votre mot de passe
2. **+ Ajouter** : créez un cabinet (nom obligatoire, autres champs optionnels)
3. **Modifier** : éditez les champs, le sélecteur de départements se remplit par recherche (tapez `75`, `Paris`…)
4. **Voir les changements** (dans la feuille d'édition) : vérifiez le récapitulatif avant d'enregistrer — c'est ce qui sera publié immédiatement sur la carte
5. **Historique** (bouton en haut) : consultez les modifications des 30 derniers jours, champ par champ (avant → après)
6. **Supprimer** : demande une confirmation, l'action est tracée

> Chaque enregistrement est publié **immédiatement** sur la carte publique. Pas de bouton "publier" séparé.
